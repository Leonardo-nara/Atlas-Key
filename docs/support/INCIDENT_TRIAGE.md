# Triagem de Incidentes

## Critico

- Dados expostos.
- Pagamento marcado incorretamente em escala.
- Pedidos/vendas corrompidos.
- API indisponivel para todos.

Acao: congelar deploys, preservar evidencias, conter risco e corrigir em branch isolada.

## Alto

- Fluxo principal bloqueado para uma empresa.
- Estoque ou caixa inconsistente com impacto real.
- Upload ou login indisponivel para grupo relevante.

## Medio

- Erro com contorno manual.
- Problema visual que atrapalha, mas nao impede operacao.

## Baixo

- Texto, espaco, estado vazio, lentidao pontual ou melhoria.
