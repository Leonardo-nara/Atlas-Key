## Estado atual

O `app.json` nao aponta para assets customizados de icon/splash. Antes de enviar para a Play Console, fornecer ou aprovar assets finais do Mototake.

## Regra de versionamento

Se qualquer asset mobile entrar depois que o AAB versionCode 1 for enviado para a Play Console, incrementar `android.versionCode` para `2` antes de gerar novo AAB.
