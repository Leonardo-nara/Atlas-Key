# Checklist do piloto real

Use uma copia deste checklist para cada empresa. Nao versionar dados pessoais reais neste arquivo.

- [ ] Nome oficial da empresa: `<preencher fora do Git>`
- [ ] Nome comercial: `<preencher fora do Git>`
- [ ] Responsavel: `<preencher fora do Git>`
- [ ] E-mail do administrador: `<preencher fora do Git>`
- [ ] Telefone: `<preencher fora do Git>`
- [ ] Endereco completo: `<preencher fora do Git>`
- [ ] Cidade, estado e CEP: `<preencher fora do Git>`
- [ ] Timezone confirmado
- [ ] Metodos de pagamento confirmados
- [ ] Operacao com delivery/retirada/PDV confirmada

## Cadastro e acesso

- [ ] Dry-run de criacao executado
- [ ] Duplicidade de loja verificada
- [ ] Duplicidade de e-mail verificada
- [ ] Empresa criada
- [ ] Administrador criado
- [ ] Credencial temporaria armazenada apenas em `.demo-local/`
- [ ] Primeiro login realizado
- [ ] Acesso de loja validado
- [ ] Acesso admin global bloqueado para `STORE_ADMIN`

## Configuracao operacional

- [ ] Perfil da loja revisado
- [ ] Produtos cadastrados
- [ ] Precos revisados
- [ ] Estoque configurado
- [ ] Taxas por bairro cadastradas
- [ ] Pix manual configurado, se usado
- [ ] Dinheiro/cartao configurados operacionalmente
- [ ] Caixa configurado
- [ ] Motoboys vinculados
- [ ] Prontidao validada

## Teste controlado

- [ ] Pedido controlado criado
- [ ] Pedido aceito pela loja
- [ ] Taxa de entrega validada
- [ ] Motoboy atribuido ou retirada validada
- [ ] Entrega concluida
- [ ] Estoque validado
- [ ] Pagamento validado
- [ ] Venda PDV controlada
- [ ] Fechamento de caixa controlado
- [ ] Relatorio revisado

## Treinamento e aprovacao

- [ ] Equipe treinada
- [ ] Responsavel aprovou operacao
- [ ] Canal de suporte confirmado
- [ ] Data/hora de inicio registrada fora do Git

## Monitoramento

- [ ] `pilot:check:prod` executado no Dia 0
- [ ] `pilot:check:prod` executado no Dia 1
- [ ] Alertas revisados
- [ ] Melhorias registradas fora do Git
