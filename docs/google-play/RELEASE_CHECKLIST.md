# Checklist de Release Google Play - Mototake

## Antes de criar o app

- [ ] Razao social, CNPJ e endereco definidos.
- [ ] E-mail de suporte definido.
- [ ] E-mail de privacidade definido.
- [ ] Politica de privacidade revisada por advogado.
- [ ] Termos revisados por advogado.
- [ ] URL de exclusao de conta publicada.
- [ ] Icone 512 x 512 aprovado.
- [ ] Feature graphic 1024 x 500 aprovado.
- [ ] Screenshots de telefone aprovadas.
- [ ] AAB production validado.

## Tecnico

- [ ] Package `com.souzaworks.mototake`.
- [ ] Version name `1.0.0`.
- [ ] Version code incremental.
- [ ] API production.
- [ ] Sem localhost.
- [ ] Sem sandbox.
- [ ] Sem secrets no bundle.
- [ ] Push real desligado se nao configurado.
- [ ] Gateway/Pix automatico desligado.

## Play Console

- [ ] App criado.
- [ ] Store listing preenchida.
- [ ] Data Safety preenchido.
- [ ] Content Rating preenchido.
- [ ] Target audience preenchido.
- [ ] Politica de privacidade informada.
- [ ] Teste interno criado.
- [ ] Teste fechado planejado.
